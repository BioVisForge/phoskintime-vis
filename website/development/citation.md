# Cite

Use the repository's [`CITATION.cff`](https://github.com/BioVisForge/phoskintime-vis/blob/main/CITATION.cff);
GitHub's **Cite this repository** button formats it for you.

```bibtex
@software{mishra_phoskintime_vis,
  author  = {Mishra, Abhinav},
  title   = {PhosKinTime-Vis: offline viewer and run comparison for PhosKinTime run bundles},
  version = {0.1.0},
  url     = {https://github.com/BioVisForge/phoskintime-vis}
}
```

When the science matters, cite [PhosKinTime](https://github.com/bibymaths/phoskintime) too.
