# PhosKinTime-Vis 0.1.0

First release of the offline viewer and run-comparison tool for PhosKinTime run bundles.

## Highlights

- Opens a run bundle (`<run>.pkt/` folder or `<run>.pkt.zip`), checks every file's sha256 and
  redraws PhosKinTime's protwise and networkmodel plots from the stored data.
- Compares two runs: provenance, fit per layer, trajectory overlay, per-state differences,
  parameter changes, and an HTML + CSV report.
- Exports every panel as PNG (600 dpi by default), vector PDF, SVG, CSV and TikZ/PGFPlots at
  journal widths. Text is never scaled below the chosen size without your confirmation.
- One self-contained HTML file that works offline from `file://`. Nothing is uploaded.

## Supported bundle schema

1.0 **DRAFT**, written in this repository. PhosKinTime has not published a bundle schema or the
`phoskintime bundle` command yet, so the bundles that exist today are the synthetic spec
fixtures. 1.x loads with a notice; 2.0 and newer are refused.

## Known limitations

- The What-if view runs only against a mock engine and is hidden behind `?engine=mock`.
- Several panels need data PhosKinTime does not save yet (observed protwise mRNA and protein,
  steady-state dynamics, kinase activity as the model uses it, among others).
- At single-column width (85 mm) panels with long parameter labels ask you to choose a fix before
  exporting.
- TikZ files with many points need LuaLaTeX.
